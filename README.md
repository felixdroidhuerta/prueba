# Fingerprint Attendance System

Este proyecto proporciona un ejemplo de aplicación de fichaje por huella dactilar compatible con Raspberry Pi. Utiliza Python, SQLite y una interfaz gráfica Tkinter. 

## Requisitos
- Python 3
- Biblioteca de control para el lector de huella (no incluida, se debe adaptar a su modelo)

## Ejecución
```
python3 src/app.py
```
